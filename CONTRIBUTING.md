# Contributing to the OTAC 0.1.x historical line

OTAC 0.1.x is frozen except for documentation, reproducibility, test, and
repository-hygiene corrections. New protocol capabilities belong in separately
reviewed future work.

Useful contributions include:

- corrections that make the documented prototype behavior more precise;
- JCS/SHA-256 regression and negative tests;
- reproducibility fixes that do not expand the protocol scope;
- additional verified errata.

Do not describe PQC, CBOR, trust, time, sharding, or compliance as implemented
without executable code, negative tests, and an explicit scope decision.

Open an issue before a substantial change. Send security reports privately to
**nyxquantum@proton.me**.
